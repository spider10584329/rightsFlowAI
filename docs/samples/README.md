# Sample files (for manual testing only)

These files contain **fictional test data**. They are not real royalty records.
Use them to try the import flows in a development organization:

- `sample-distributor-statement.csv`: a distributor-style sales report.
  1. Create recordings with ISRC `QZSAM2600001` and `QZSAM2600002` in the catalog.
  2. Add master ownership shares for those recordings.
  3. Upload this file under **Royalties → Statements** to see the result: ISRC matching, one unmatched line, and calculation.
